# Tiến Lên Miền Nam

Game bài Tiến Lên Miền Nam cho điện thoại: bạn đấu với 3 bot (Tây, Đông, Bắc). Để máy dọc thì game tự xoay 90° thành màn hình ngang.

## Cấu trúc

- `index.html` — khung trang, bàn chơi, overlay thắng/thua
- `style.css` — giao diện bàn xanh, lá bài, responsive theo chiều cao
- `game.js` — luật Tiến Lên (đơn/đôi/sám/sảnh/tứ quý/đôi thông chặt heo), bot AI, chặn thiết bị không phải điện thoại (PC sẽ hiện thông báo; máy dọc tự xoay game 90°)

## Chơi thử

Bật GitHub Pages cho repo (Settings → Pages → Deploy from a branch → `main` / `(root)`), sau đó mở trên điện thoại:

https://kanz510.github.io/Tienlenmiennam/

Xoay ngang máy là vào ván. Người giữ 3♠ đi trước, và nước đi đầu tiên của ván bắt buộc phải có 3♠.
